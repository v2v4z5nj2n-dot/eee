# MOEX Scanner Bot

Telegram-бот, который каждый будний вечер проверяет акции Мосбиржи и присылает сценарий сделки
(вход, стоп, две цели, прибыль/риск), если находит:

1. **сильную просадку при росте объёма** (≥10% от максимума за 10 дней и объём ≥1,5× от среднего;
   падения из-за дивидендной отсечки отфильтровываются);
2. **технические сигналы**: RSI < 30, возврат RSI выше 30, пробой 20-дневного максимума на объёме,
   пересечение SMA20 и SMA50 снизу вверх.

Бот ничего не покупает и не продаёт, он только присылает уведомления. Это не инвестиционная рекомендация.

## Быстрый старт (Windows / Mac / Linux)

1. Установите Python 3.10+ (python.org). Откройте терминал в папке бота и выполните:
   `pip install -r requirements.txt`
2. В Telegram найдите **@BotFather** → `/newbot` → придумайте имя → скопируйте **токен**.
3. Скопируйте `.env.example` в `.env` и вставьте токен в `BOT_TOKEN=`.
4. Запустите: `python bot.py run`, затем напишите своему боту `/start`. Бот ответит вашим **chat id**.
5. Впишите его в `.env` в `CHAT_ID=`, остановите бота (Ctrl+C) и запустите снова: `python bot.py run`.

Команды в Telegram: `/scan`, `/check SBER`, `/list`, `/add TICKER`, `/remove TICKER`, `/help`.
Автоматический скан идёт по будням в 19:00 МСК (после закрытия основной сессии).

## Сначала проверьте правила на истории

`python bot.py backtest` — прогон правил на ~3 годах дневных данных по вашему списку. Для каждого типа сигнала
покажет число сделок, долю в плюсе, средний результат, средний R и сколько сделок дошло до цели или выбито по стопу.
Если у сигнала средний результат отрицательный или сделок мало, не доверяйте ему и поменяйте пороги в блоке `C` в начале `bot.py`.

## Другие режимы

- `python bot.py scan` — один скан и выход (для планировщика cron / Task Scheduler); `--force` игнорирует паузу между алертами.
- `python bot.py check SBER` — метрики и сигналы по одной бумаге.

## Чтобы бот работал 24/7

Компьютер должен быть включён. Надёжнее арендовать маленький VPS (несколько $ в месяц), закинуть туда папку и запустить
`python bot.py run` через `systemd` или `tmux`. Бот сам читает команды из Telegram, открывать порты не нужно.

## Что настраивается (блок `C` в bot.py)

Порог просадки, множитель объёма, пороги RSI, минимальное соотношение прибыль/риск, пауза между алертами,
фильтр ликвидности, время скана. Список бумаг меняется командами `/add` и `/remove`.

## Ограничения (важно)

- Данные — открытый API Мосбиржи (ISS), бесплатные котировки могут идти с задержкой около 15 минут; для дневных свечей этого достаточно.
- Тикеры в списке по умолчанию проверьте сами: если тикер не найден на доске TQBR, бот его пропустит и сообщит об ошибке.
- Бот не знает новостей: падение может быть вызвано отчётностью, санкциями или решением регулятора. Всегда смотрите новости перед сделкой.
- Правила дают ложные сигналы; стоп-лосс и размер позиции обязательны. Бэктест не гарантирует будущих результатов.
- Размер лота в подсказке по объёму не учитывается.
